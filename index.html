HOW TO USE

SPACEBAR Start / Pause
C Clear Canvas

PARAMETER GUIDE

OPACITY (ALPHA)
Color transparency. Low = Watercolor. High = Oil.
SENSITIVITY
Microphone gain. If brush doesn't react, increase this.
SPEED
Brush engine power. How fast it flies forward.
CHAOS
Line jitter. 0% = Smooth curves. 100% = Wild scribbles.
VISCOSITY
Drag/Friction. High = Brush stops immediately.
PITCH GRAVITY
0% = Off. 100% = Low notes pull down, High notes pull up.
